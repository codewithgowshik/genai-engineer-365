# Day 101 — Build the Search Backend

## Objective

Learn the basic architecture of a search backend and build the search component for Project 3: Semantic Search Engine.

## What I Learned

### What Is Architecture?

Architecture describes how the different parts of a system connect and work together.

```text
Documents
    ↓
Ingestion
    ↓
Chroma Database
    ↑
    │
User Query
    ↓
Search Backend
    ↓
Query Embedding
    ↓
Similarity Search
    ↓
Top-K Results
```

The search backend connects the user's query to the vector database and returns relevant results.

## What Is a Search Backend?

The search backend is the part of the application that receives a search query and performs the search.

```text
User Query
    ↓
Search Logic
    ↓
Chroma
    ↓
Relevant Documents
```

## Today's Build

I created `src/search.py`.

The search backend:

1. Loads the embedding model.
2. Connects to the Chroma database.
3. Gets the existing `documents` collection.
4. Accepts a user query.
5. Converts the query into an embedding.
6. Searches Chroma using the query embedding.
7. Retrieves the top-K results.
8. Returns the results.

## Search Function

```python
def search(query, k=3):

    query_embedding = model.encode(query)

    results = collection.query(
        query_embeddings=[
            query_embedding.tolist()
        ],
        n_results=k
    )

    return results
```

## Understanding the Function

### `query`

```python
def search(query, k=3):
```

`query` is what the user wants to search for.

Example:

```text
"I want to learn programming"
```

### `k`

`k` controls how many results should be returned.

```python
k=3
```

means:

```text
Return the top 3 results.
```

## Query Embedding

The query is converted into an embedding:

```python
query_embedding = model.encode(query)
```

```text
User Query
    ↓
Embedding Model
    ↓
Query Vector
```

This allows the query to be compared with vectors stored in Chroma.

## Searching Chroma

```python
results = collection.query(
    query_embeddings=[
        query_embedding.tolist()
    ],
    n_results=k
)
```

Chroma compares the query vector with stored vectors and returns the closest results.

## Why Return the Results?

```python
return results
```

This gives the search results back to the part of the application that called the search function.

This makes the search logic reusable.
