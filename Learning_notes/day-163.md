# 1. Introduction to Fine-Tuning

Fine-tuning is the process of taking an already pretrained AI model and training it further using a specialised dataset.

The goal is to adapt the model's behaviour or improve its performance on a particular task.

For example, imagine we have a general-purpose AI model.

It can:
- Answer general questions.
- Summarise documents.
- Translate languages.
- Generate text.

However, we want to create an AI assistant specifically for customer support.

We can prepare customer-support examples and use them to fine-tune the existing model.

The model can learn patterns from these examples and become better suited to the task.

**Key concept:** Fine-tuning adapts an existing pretrained model rather than training a completely new model from scratch.

---

# 2. Types of Fine-Tuning

There are several approaches to adapting an AI model.

## 2.1 Supervised Fine-Tuning (SFT)

Supervised Fine-Tuning is a method of training an AI model using examples containing instructions and expected responses.

The model learns from these examples.

### Example

**Instruction:**

Explain artificial intelligence to a beginner.

**Expected Output:**

Artificial intelligence is technology that allows computers to perform tasks that normally require human intelligence.

We provide many high-quality examples like this during training.

The model learns how to respond to similar instructions.

### Where is SFT useful?

- Chatbots.
- Customer-support assistants.
- AI writing assistants.
- Instruction-following models.
- Task-specific AI applications.

**Remember:** SFT teaches a model through instruction-and-answer examples.

---

## 2.2 Preference Fine-Tuning

Sometimes an AI model generates multiple answers to the same question.

Some answers are better than others.

Preference fine-tuning helps models learn which responses humans prefer.

### Example

**Question:**

Explain AI in simple English.

**Answer A:**

AI is a computational paradigm involving sophisticated algorithms.

**Answer B:**

AI is technology that helps computers perform tasks that normally require human intelligence.

A beginner would probably prefer Answer B.

Preference data can contain:
- A question or prompt.
- A preferred response.
- A rejected response.

Two important preference-optimisation approaches are:

### RLHF – Reinforcement Learning from Human Feedback

RLHF uses human feedback to help improve a model's behaviour.

A simplified process:

1. The model generates responses.
2. Humans evaluate the responses.
3. A reward model learns human preferences.
4. Reinforcement learning is used to optimise the model.

### DPO – Direct Preference Optimization

DPO is an approach that directly uses preference comparisons to optimise a model.

It avoids the separate reward-model and reinforcement-learning pipeline commonly associated with traditional RLHF.

**Remember:** Preference fine-tuning teaches models which responses are more desirable.

---

## 2.3 Continued Pretraining

Continued pretraining means taking an existing pretrained model and training it further on additional text.

For example, imagine we have a general-purpose language model.

We want it to become more familiar with financial terminology.

We can provide a large collection of financial documents as additional training data.

The model continues learning language patterns and domain-specific information.

### Where is it useful?

- Domain adaptation.
- Scientific language.
- Financial terminology.
- Legal terminology.
- Specialised technical documents.

**Important:** Continued pretraining is different from instruction fine-tuning. It generally focuses on learning from additional text rather than learning specific instruction-response behaviour.

---

## 2.4 Parameter-Efficient Fine-Tuning (PEFT)

Full fine-tuning can require significant GPU memory and computational resources.

Parameter-Efficient Fine-Tuning (PEFT) reduces the number of parameters that need to be trained.

One popular PEFT technique is LoRA.

### What is LoRA?

LoRA stands for Low-Rank Adaptation.

Instead of updating all the original model parameters, LoRA introduces smaller trainable components that adapt the model.

This can reduce:
- GPU memory requirements.
- Training costs.
- Number of trainable parameters.
- Storage requirements for model adaptations.

### Full Fine-Tuning vs LoRA

| Full Fine-Tuning | LoRA |
|---|---|
| Updates many or all model parameters | Trains additional low-rank parameters |
| Requires more resources | Often requires fewer resources |
| Can produce a full updated model | Stores a smaller adaptation |
| Can be computationally expensive | More resource-efficient |

**Remember:** LoRA is a technique for making fine-tuning more efficient.

# 3. Comparison of Fine-Tuning Approaches

| Approach | Main Purpose |
|---|---|
| Supervised Fine-Tuning (SFT) | Learn from instructions and expected answers |
| Preference Fine-Tuning | Learn from preferred and rejected responses |
| RLHF | Improve behaviour using human feedback |
| DPO | Optimise using preference comparisons |
| Continued Pretraining | Learn from additional text |
| PEFT | Reduce the resources needed for fine-tuning |
| LoRA | Adapt a model using additional low-rank parameters |

### Important distinction

These approaches are not all separate alternatives at the same level.

- SFT and preference optimisation describe training approaches.
- RLHF and DPO are preference-alignment methods.
- Continued pretraining uses additional text for further language-model training.
- PEFT describes a family of resource-efficient adaptation techniques.
- LoRA is one technique within PEFT.

# 4. What Is an Instruction Dataset?

An instruction dataset is a collection of examples that show an AI model how to perform particular tasks.

It is commonly used for Supervised Fine-Tuning.

Each example can contain:

1. Instruction
2. Input
3. Output

### Example

**Instruction:**

Translate the following sentence into Tamil.

**Input:**

Good morning. How are you?

**Output:**

காலை வணக்கம். நீங்கள் எப்படி இருக்கிறீர்கள்?

The dataset contains many examples of this structure.

During supervised fine-tuning, the model learns from the examples.

# 5. Understanding JSONL

JSONL stands for **JSON Lines**.

It is a text-based data format where each line contains one independent JSON object.

### JSON vs JSONL

**JSON example:**

```json
[
  {
    "instruction": "Explain AI.",
    "input": "",
    "output": "AI allows computers to perform tasks that normally require human intelligence."
  },
  {
    "instruction": "Explain machine learning.",
    "input": "",
    "output": "Machine learning allows computers to learn patterns from data."
  }
]
```

**JSONL example:**

```jsonl
{"instruction":"Explain AI.","input":"","output":"AI allows computers to perform tasks that normally require human intelligence."}
{"instruction":"Explain machine learning.","input":"","output":"Machine learning allows computers to learn patterns from data."}
```

### Main Differences

| JSON | JSONL |
|---|---|
| Can contain arrays and objects | Each line is an independent JSON value |
| Often uses commas between array elements | No commas between records |
| Commonly used for API data and configuration | Useful for large datasets and training examples |
| Usually stored as `.json` | Usually stored as `.jsonl` |

**Remember:** One JSON object per line.

# 6. Understanding the Three Dataset Fields

Our instruction dataset uses three fields.

## 6.1 Instruction

Defines what we want the AI model to do.

Example:

```json
"instruction": "Explain artificial intelligence in simple English."
```

## 6.2 Input

Provides additional information needed to complete the task.

Example:

```json
"input": "Artificial intelligence is changing education."
```

Sometimes the input can be empty.

## 6.3 Output

Contains the expected response.

Example:

```json
"output": "AI is changing education by helping students learn more effectively."
```

### Complete Example

```json
{
  "instruction": "Summarise the following sentence.",
  "input": "Artificial intelligence is transforming education through personalised learning.",
  "output": "AI is improving education through personalised learning."
}
```

# 7. How Instruction Fine-Tuning Works

A simplified supervised fine-tuning workflow:

```text
        Collect Examples
               |
               v
       Create Dataset
               |
               v
        Validate Data
               |
               v
      Format Training Data
               |
               v
       Load Pretrained Model
               |
               v
       Run Fine-Tuning
               |
               v
       Evaluate the Model
               |
               v
       Adapted AI Model
```

### Step-by-step explanation

**Step 1 – Collect Examples**

Prepare high-quality instructions and expected answers.

**Step 2 – Create Dataset**

Store the examples in a suitable format, such as JSONL.

**Step 3 – Validate Data**

Check that every record is valid and contains the required fields.

**Step 4 – Format Training Data**

Convert the examples into the format expected by the training framework or model.

**Step 5 – Load Pretrained Model**

Choose an existing model to fine-tune.

**Step 6 – Run Fine-Tuning**

Train the model using the prepared dataset.

**Step 7 – Evaluate the Model**

Test whether the fine-tuned model performs better on the intended task.

**Step 8 – Use the Adapted Model**

Deploy or use the model for the intended application.

# 8. Important Dataset Quality Principles

Creating a dataset is not just about adding many examples.

The quality of the examples matters.

### 1. Accuracy

Every expected answer should be correct.

### 2. Consistency

Use a consistent structure across all records.

### 3. Diversity

Include different types of instructions and examples.

### 4. Clarity

Instructions should be easy to understand.

### 5. Relevance

Examples should relate to the task we want the model to learn.

### 6. Avoid Duplicates

Repeated examples can reduce dataset diversity.

### 7. Data Validation

Ensure every JSONL line is valid JSON and follows the expected schema.
