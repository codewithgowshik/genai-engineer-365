# Day 110 — Reproducibility & Sample Dataset

## Objective

Learn what reproducibility means in a software project and add a small sample dataset to the Semantic Search Engine so another person can test the project.

## 1. What is Reproducibility?

Reproducibility means that another person should be able to take your project, follow the instructions, use the included data, and reproduce the core result.

For this project:

```text
Sample Dataset
      ↓
   Ingestion
      ↓
   Embeddings
      ↓
    Chroma
      ↓
 Semantic Search
      ↓
    Results
```

The goal is not just to make the project work on your computer. The goal is to make it understandable and testable by someone else.

## 2. Why Does a Sample Dataset Matter?

If a GitHub repository contains only code, someone cloning the project may not know what data to use.

A sample dataset provides a small, controlled collection of documents that can be used immediately.

For this project, the dataset is stored in:

```text
data/documents.txt
```

The current ingestion script reads the file line by line, so each line represents one document.

## 4. How the Dataset Enters the Search Engine

The ingestion process takes the text documents and prepares them for search.

```text
documents.txt
     ↓
Read documents
     ↓
Create document IDs
     ↓
Generate embeddings
     ↓
Store in Chroma
```

The embedding model converts each document into a numerical vector.

Chroma then stores the documents and their vector representations.

Later, when a user searches:

```text
User Query
    ↓
Query Embedding
    ↓
Vector Similarity Search
    ↓
Relevant Documents
```

## 5. Testing Semantic Search

After adding the dataset, run:

```bash
python src/ingest.py
```

Then start the Streamlit application:

```bash
streamlit run app.py
```

Test queries that do not necessarily use the exact wording from the documents.

Example:

```text
How do computers learn from information?
```

This should retrieve information related to machine learning.

Another example:

```text
How can I search documents by meaning?
```

This should retrieve information related to semantic search.

Another example:

```text
What stores numerical representations of text?
```

This should retrieve information related to vector databases or embeddings.

The purpose of these tests is to demonstrate that the system can retrieve related information based on meaning.

## 6. Reproducibility in This Project

The project is becoming more reproducible because it now contains:

```text
Code
+
Sample Dataset
+
README
+
Architecture Documentation
+
Screenshots
```

A person viewing the repository has the resources needed to understand and test the project.

This is an important difference between:

```text
"My code works."
```

and:

```text
"Someone else can reproduce what I built."
```
