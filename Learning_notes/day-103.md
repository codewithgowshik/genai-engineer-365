## 1. What is Evaluation?

Evaluation means checking whether a search engine is producing useful and relevant results.

A search engine returning results does not automatically mean that the results are good.

The main question is:

> **Are the retrieved results relevant to the user's query?**

For example:

```text
Query:
"What is a programming language?"
```

Expected relevant document:

```text
doc1 → Python is a programming language.
```

If the search returns:

```text
doc3 → Pizza is a popular Italian food.
```

the system returned a result, but it is not relevant to the query.

---

## 2. Relevance

**Relevance** describes whether a retrieved document is useful for the user's query.

Example:

```text
Query:
"I want to learn programming"

Result:
"Python is a programming language."
```

This is relevant.

But:

```text
Result:
"London is the capital of the United Kingdom."
```

is not relevant to that query.

## 5. Add a Result Filter

Use Streamlit's `selectbox()` to let the user choose the number of results.

```python
k = st.selectbox(
    "Number of results",
    [1, 2, 3, 4]
)
```

The selected value is stored in `k`.

Then pass it to the existing search backend:

```python
results = search(query, k=k)
```

This means the user controls the number of returned results.

The flow is:

```text
User chooses number of results
          ↓
            k
          ↓
search(query, k=k)
          ↓
       Chroma
          ↓
      Top-K results
```

## 6. Improved `app.py`

The Day 103 version can be:

```python
import streamlit as st
from src.search import search


st.title("Semantic Search Engine")

query = st.text_input("Enter your search query")

k = st.selectbox(
    "Number of results",
    [1, 2, 3, 4]
)

if st.button("Search"):

    if query.strip() == "":
        st.warning("Please enter a search query.")

    else:
        results = search(query, k=k)

        st.subheader("Search Results")

        documents = results["documents"][0]

        for i, document in enumerate(documents):

            st.write(f"### Result {i + 1}")

            st.write(document)

            st.divider()
```

## 8. Result Display

The results are displayed individually.

```python
for i, document in enumerate(documents):
```

loops through the returned documents.

This:

```python
st.write(f"### Result {i + 1}")
```

creates a clear heading for each result.

This:

```python
st.write(document)
```

displays the document.

This:

```python
st.divider()
```

separates the results visually.

The goal is to make search results easier to read.

---

## 9. Evaluation vs Filters

These concepts have different purposes.

### Evaluation

Answers:

> **Is my search engine returning relevant results?**

### Filter

Answers:

> **How many results does the user want to see?**

### Result Display

Answers:

> **How should the results be presented to the user?**

So:

```text
Evaluation
    ↓
Measure search quality

Filter
    ↓
Control the results shown

Result Display
    ↓
Present results clearly
```
