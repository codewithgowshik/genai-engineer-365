## 3. Iterating on Chunking

Chunking means splitting text into smaller pieces before creating embeddings and searching them.

The previous basic chunking approach used a fixed character size:

```python
def chunk_text(text, chunk_size):
    return [
        text[i:i + chunk_size]
        for i in range(0, len(text), chunk_size)
    ]
```

A fixed character size can split a sentence in the middle.

For example:

```text
Python is a programming lang
uage used for many applicatio
ns.
```

This can make individual chunks less meaningful.

---

## 4. Sentence-Based Chunking

A simple alternative is to split the text into sentences.

```python
def chunk_text(text):

    sentences = text.split(".")

    chunks = []

    for sentence in sentences:

        sentence = sentence.strip()

        if sentence != "":
            chunks.append(sentence + ".")

    return chunks
```

For example:

```text
Python is a programming language. Python is useful for data analysis.
```

can become:

```text
Chunk 1:
Python is a programming language.

Chunk 2:
Python is useful for data analysis.
```

The chunks are closer to complete sentences and can preserve more meaningful units of text.

---

## 5. Why Does Chunking Matter?

The search pipeline is:

```text
Documents
    ↓
Chunks
    ↓
Embeddings
    ↓
Vector Search
    ↓
Results
```

The embedding represents the chunk.

Therefore, the quality of the chunks can affect the quality of search results.

The goal is not simply to make chunks smaller. The goal is to create chunks that contain useful meaning.

## 6. Iterating on Ranking

The project already has a basic hybrid search approach from Day 96.

Hybrid search combines:

```text
Keyword Score
      +
Vector Score
```

The previous experiment used:

```text
Combined Score =
(Keyword Score × 0.3)
+
(Vector Score × 0.7)
```

This means:

```text
Keyword = 30%
Vector  = 70%
```

---

## 8. Why Experiment With Ranking?

Keyword search is useful when exact words matter.

Vector search is useful when meaning and semantic similarity matter.

Hybrid search combines both signals.

The ranking weights control how strongly each signal influences the final ranking.

```text
Keyword weight
      +
Vector weight
      ↓
Combined ranking
```

The important engineering question is not:

> Which weight is always best?

Instead:

> Which configuration performs better on my current test set?

## 12. Important Engineering Habit

Today's most important lesson is the iteration loop:

```text
Change
  ↓

  ↓
Observe
  ↓

  ↓
```

Instead of deciding that a configuration is better based on intuition, use the evaluation results to support the decision.
