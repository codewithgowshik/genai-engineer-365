## 1. What is Hugging Face?

Hugging Face is a platform and ecosystem for discovering, sharing, and using machine-learning models and datasets. Its Model Hub hosts pretrained models that developers can download and run.

## 2. What is Transformers?

The Hugging Face **Transformers** library provides Python tools for loading pretrained transformer models, preparing inputs, and running tasks such as text generation, classification, and question answering.

For this session, we use a causal language model to generate text.

## 3. Key components

| Component | Purpose |
|---|---|
| Model Hub | Hosts pretrained models and related files |
| Transformers | Loads models and provides inference utilities |
| Tokenizer | Converts text into token IDs the model can process |
| Model | Uses learned parameters (weights) to predict tokens |
| PyTorch | Tensor and deep-learning framework used to run the model |
| Inference | Using a trained model to produce a prediction or output |

## 4. How text generation works

1. The user enters a text prompt.
2. The tokenizer converts the prompt into token IDs.
3. The model processes those IDs.
4. The model predicts and generates additional tokens.
5. The tokenizer decodes the token IDs into readable text.

**Flow:**

```text
Text prompt
    |
    v
Tokenizer
    |
    v
Token IDs
    |
    v
Pretrained model
    |
    v
Generated token IDs
    |
    v
Tokenizer decode
    |
    v
Generated text
```

## 5. Model used: DistilGPT-2

`distilgpt2` is a smaller, distilled version of GPT-2. It is useful for learning basic text-generation workflows and is relatively lightweight compared with many modern language models.

It is not a modern instruction-following assistant, so its output may be repetitive, incomplete, or unrelated to a prompt. This is expected.

## 6. Important code concepts

- `AutoTokenizer.from_pretrained(MODEL_NAME)`: downloads or loads the tokenizer associated with the model.
- `AutoModelForCausalLM.from_pretrained(MODEL_NAME)`: downloads or loads a pretrained causal language model.
- `tokenizer(prompt, return_tensors="pt")`: tokenizes the prompt and returns PyTorch tensors.
- `model.generate(...)`: generates new token IDs from the input.
- `max_new_tokens=100`: allows up to 100 new tokens to be generated.
- `do_sample=True`: samples from the model's next-token distribution instead of always choosing the highest-scoring token.
- `temperature=0.7`: controls sampling randomness; lower values generally make sampling less random.
- `torch.no_grad()`: disables gradient calculation because training is not being performed.
- `tokenizer.decode(..., skip_special_tokens=True)`: converts generated token IDs back into readable text.
- `time.perf_counter()`: measures elapsed time with a high-resolution timer.

## 7. Installation and execution

Install the libraries:

```powershell
python -m pip install transformers torch
```

Run the application:

```powershell
python main.py
```

The first run downloads the model files from Hugging Face, so an internet connection is required. The downloaded files are cached for later use.

## 8. Hugging Face Transformers vs Ollama

| Hugging Face Transformers | Ollama |
|---|---|
| Python library for loading and running models | Local model runtime and management tool |
| Offers direct control in Python | Offers a simple CLI and local HTTP API |
| You manage model loading and inference code | Ollama manages much of the runtime setup |
| Commonly used for research, experimentation, and model development | Convenient for running and serving local models |

Both can run models locally. They provide different interfaces and workflows.

## 9. Important limitations

- Model downloads require internet access the first time.
- Hardware requirements depend on the model, its precision, and the input/context length.
- DistilGPT-2 is a small learning model, not a reliable source of factual answers.
- The measured generation time depends on hardware, model loading, input length, and generation settings.
- The example measures generation time after the model has loaded; it does not include the initial model download or loading time.

## 10. Key terms to remember

- **Pretrained model:** A model whose parameters have already been learned from training data.
- **Model weights:** The learned numerical parameters of a model.
- **Tokenizer:** Software that converts text into tokens and token IDs.
- **Token:** A unit of text processed by a language model; it may be a word, part of a word, or a character.
- **Causal language model:** A model trained to predict the next token based on preceding tokens.
- **Inference:** Running a trained model to generate an output.
- **Generation:** Producing new tokens from a prompt.
