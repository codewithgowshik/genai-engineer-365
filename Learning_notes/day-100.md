## What I Learned

### What Is Data Ingestion?

Data ingestion means taking raw data and bringing it into a system so it can be processed and used.

For the semantic search engine:

```text
Raw Documents
      ↓
Read Documents
      ↓
Prepare Documents
      ↓
Create Embeddings
      ↓
Store in Chroma
```

The ingestion pipeline prepares documents so they are ready for search.

## Why Do We Need Ingestion?

A search engine cannot search documents that have not been added to its search system.

```text
Documents
    ↓
Ingestion
    ↓
Vector Database
    ↓
Search
```

## Today's Pipeline

1. Load the embedding model.
2. Connect to Chroma.
3. Get or create the documents collection.
4. Read documents from `data/documents.txt`.
5. Remove empty lines.
6. Create IDs for the documents.
7. Create embeddings.
8. Store the documents and embeddings in Chroma.

## Today's Build

```python
import chromadb
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("all-MiniLM-L6-v2")

client = chromadb.PersistentClient(
    path="./chroma_data"
)

collection = client.get_or_create_collection(
    name="documents"
)

documents = []

with open(
    "data/documents.txt",
    "r",
    encoding="utf-8"
) as file:

    for line in file:

        line = line.strip()

        if line != "":
            documents.append(line)

ids = []

for i in range(len(documents)):

    ids.append(f"doc{i + 1}")

embeddings = model.encode(documents)

collection.upsert(
    ids=ids,
    documents=documents,
    embeddings=embeddings.tolist()
)

print("Ingestion complete!")
print("Documents stored:", collection.count())
```

## Understanding the Reading Step

The code reads the document file one line at a time:

```python
for line in file:

    line = line.strip()

    if line != "":
        documents.append(line)
```

This means:

1. Read one line.
2. Remove unnecessary whitespace.
3. Check whether the line is empty.
4. If it is not empty, add it to `documents`.

## Creating Document IDs

Each document needs an ID:

```text
doc1
doc2
doc3
doc4
```

The IDs allow Chroma to identify individual documents.

## Creating Embeddings

The embedding model converts the documents into numerical vectors:

```text
Document
   ↓
Embedding Model
   ↓
Vector
```

These vectors allow the documents to be searched using semantic similarity.

## Storing in Chroma

```python
collection.upsert(
    ids=ids,
    documents=documents,
    embeddings=embeddings.tolist()
)
```

This stores the document IDs, documents, and embeddings in the Chroma collection.
