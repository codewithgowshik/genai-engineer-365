## 1. Cost and latency

### Latency

Latency is the time taken for a system to respond to a request. For a RAG application, useful measurements include:

- **Retrieval latency:** Time taken to retrieve relevant passages from ChromaDB.
- **Reranking latency:** Time taken to score and reorder candidate passages.
- **Time to first token (TTFT):** Time from sending a request until the first generated text arrives.
- **End-to-end latency:** Total time from submitting the question until the response is complete.

Example values below are illustrative, not measured results from this project:

| Metric | Example |
|---|---:|
| Retrieval | 120 ms |
| Reranking | 250 ms |
| Time to first token | 1.1 s |
| Total response time | 3.4 s |

The first run can be slower because embedding and reranking models may need to load. Measure repeated runs to understand typical performance.

### Cost

Potential costs include Gemini input tokens (including retrieved context), Gemini output tokens, hosting, and storage. Local embedding and reranking models avoid per-request hosted-model API charges, but still consume local computing resources.

To estimate API cost, collect actual input/output token usage and apply the pricing for the selected Gemini model. Do not infer actual cost from latency alone.

## 3. Initial retrieval evaluation

Create `tests/test_evaluation.py`:

```python
import json
import time
from pathlib import Path

from src.retrieval import retrieve_and_rerank

PROJECT_ROOT = Path(__file__).resolve().parents[1]
DATASET_PATH = PROJECT_ROOT / "tests" / "evaluation_dataset.json"


def load_dataset():
    with DATASET_PATH.open(encoding="utf-8") as file:
        return json.load(file)


def test_retrieval_returns_results():
    dataset = load_dataset()
    assert dataset, "Evaluation dataset is empty."

    for item in dataset:
        results = retrieve_and_rerank(item["question"])
        assert results, f"No passages retrieved for: {item['question']}"


def test_retrieval_includes_source_metadata():
    dataset = load_dataset()
    assert dataset, "Evaluation dataset is empty."

    for item in dataset:
        results = retrieve_and_rerank(item["question"])
        assert results, f"No results for: {item['question']}"

        for result in results:
            assert "text" in result
            assert "source" in result
            assert "citation_id" in result


def test_retrieval_latency():
    dataset = load_dataset()
    assert dataset, "Evaluation dataset is empty."

    durations = []

    for item in dataset:
        start = time.perf_counter()
        retrieve_and_rerank(item["question"])
        durations.append(time.perf_counter() - start)

    average_latency = sum(durations) / len(durations)
    print(
        f"\nAverage retrieval + reranking latency: "
        f"{average_latency:.3f} seconds"
    )

    assert average_latency > 0
```

This initial suite tests retrieval availability, basic metadata, and retrieval-plus-reranking latency. It does **not** yet prove answer correctness, faithfulness, citation accuracy, abstention quality, or API cost.

## 5. Metrics to add in future evaluations

| Metric | What it measures |
|---|---|
| Retrieval hit rate | How often expected relevant evidence is retrieved |
| Answer correctness | Whether the answer matches expected facts |
| Faithfulness | Whether the answer is supported by retrieved passages |
| Citation accuracy | Whether cited sources actually support claims |
| Abstention quality | Whether unsupported questions are handled safely |
| Latency | How long the pipeline takes |
| Token usage | Gemini input and output consumption |
