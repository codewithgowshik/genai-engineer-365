# Day 179: Evaluating the Fine-Tuned Model Against the Base Model

## What I Learned

Today, I focused on understanding how to evaluate a fine-tuned language model against its original base model.

Fine-tuning does not automatically make a model better. We need to test whether the training process actually improved its performance on the target task.

### 1. Base Model vs Fine-Tuned Model

- Base Model: The original pre-trained Qwen2.5-0.5B model.
- Fine-Tuned Model: The same base model with additional LoRA-trained parameters.

The base model provides general language capabilities, while the fine-tuned model has been trained on marketing-specific examples.

### 2. Why Model Evaluation Matters

A lower training loss does not necessarily mean better real-world performance.

A model might:
- Memorise training examples.
- Generate incorrect information.
- Ignore user instructions.
- Produce repetitive responses.
- Perform poorly on unfamiliar inputs.

Evaluation helps identify these problems.

### 3. Evaluation Metrics

I identified five important evaluation criteria:

1. Relevance – Does the response answer the user's request?
2. Accuracy – Is the generated information correct?
3. Instruction Following – Does the model follow the given instructions?
4. Response Quality – Is the response clear and well structured?
5. Marketing Usefulness – Is the output practical for marketing purposes?

### 4. Fair Model Comparison

To compare both models fairly, they should receive:

- The same prompts.
- The same input data.
- The same generation settings.
- The same evaluation criteria.

This helps identify whether the improvements come from fine-tuning rather than different testing conditions.

### 5. Important Concepts

- Benchmarking: Comparing models using consistent tests.
- Generalisation: Performing well on previously unseen inputs.
- Overfitting: Memorising training examples instead of learning general patterns.
- Inference: Generating responses using a trained model.
- Evaluation Dataset: A separate dataset used to measure model performance.

## Mental Model

Fine-tuning teaches a model a specialised task. Evaluation tells us whether it actually learned that task or simply memorised the training examples.
