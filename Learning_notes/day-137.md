## 1. What is an LLM-as-a-judge?

An LLM-as-a-judge uses one language model to evaluate the output of another language model.

In a RAG application, the judge can check whether the generated answer is supported by the retrieved context.

Give the judge:
1. The original question.
2. The retrieved context.
3. The generated answer.

Ask it to assess the answer against a clear criterion and return a score with a short explanation.

An LLM judge is not guaranteed to be correct. Treat its scores as estimates rather than ground truth.

## 2. Why use a RAG evaluation framework?

A RAG evaluation framework helps test a retrieval-augmented generation system in a structured way.

Instead of checking only whether an answer sounds correct, evaluate parts of the pipeline using test questions and defined metrics.

For example, evaluation can help investigate:
- Whether the retrieved context contains useful information.
- Whether the answer is supported by that context.
- Whether the answer addresses the question.

## 3. What is Ragas?

Ragas is a framework designed to help evaluate RAG systems.

For this learning task, the goal is to try Ragas with the existing RAG project and explore how an evaluation metric can assess generated answers.

The intended workflow is:

```text
Evaluation question
        |
        v
Retrieve relevant documents
        |
        v
Retrieved context
        |
        v
Generate an answer
        |
        v
Evaluate the question, context, and answer
        |
        v
Review the evaluation result
```
