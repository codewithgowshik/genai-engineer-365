# Day 54 / 365 – Validate Tool Arguments with Pydantic

## 🎯 Objective

Today I improved the reliability of my AI agent by validating tool arguments using **Pydantic**.

Instead of trusting the arguments generated by the Large Language Model (LLM), my application now validates them before executing any tool. This prevents invalid data from reaching the tool and improves the overall robustness of the system.

---

# Why Validation is Important

When an LLM decides to call a tool, it generates arguments in JSON format.

Example:

```json
{
    "query": "Latest AI news"
}
```

Although the LLM usually produces correct arguments, it can occasionally generate:

- Missing fields
- Incorrect data types
- Invalid values
- Unexpected keys

Without validation, these errors may cause the application to fail or produce incorrect results.

---

# What is Pydantic?

Pydantic is a Python library used for **data validation**.

It converts raw input into strongly typed Python objects while automatically checking that the data follows the expected schema.

Instead of manually checking every value, Pydantic performs validation automatically.

Installation:

```bash
pip install pydantic
```

Import:

```python
from pydantic import BaseModel
```

# Improved Workflow

After introducing Pydantic:

```text

↓

Gemini

↓

Tool Arguments

↓

Pydantic Validation

↓

Valid?

├── Yes
│      ↓
│   Execute Tool
│
└── No
       ↓
Return Validation Error
```

The tool is executed only if the arguments pass validation.

---

# Creating a Validation Model

Every tool can have its own input model.

Example:

```python
from pydantic import BaseModel

class SearchInput(BaseModel):
    query: str
```

Now every search request must contain:

- query
- type: string

---

# PDF Tool Validation

Example:

```python
class PDFInput(BaseModel):
    file_path: str
```

The PDF reader now expects a valid file path before execution.

---

# Why Use Models?

Instead of manually checking every field:

```python
if "query" not in args:
    ...
```

```python
if not isinstance(args["query"], str):
    ...
```

Pydantic performs all validation automatically.

This results in cleaner and more maintainable code.

---

# Validation Process

The complete workflow is:

```text
Gemini Tool Call

↓

JSON Arguments

↓

Pydantic Model

↓

Validated Python Object

↓

Execute Tool
```

Only validated objects are passed to the tool.

---

# Example

Gemini returns:

```json
{
    "query": "Latest AI news"
}
```

Validation:

```python
validated = SearchInput(**tool_args)
```

The tool receives:

```python
validated.query
```

instead of raw JSON.

---

# Invalid Example

Gemini returns:

```json
{
    "query": 12345
}
```

Pydantic detects that:

- Expected: string
- Received: integer

The validation fails before the tool executes.

---

# Error Handling

Instead of crashing, the application should return a meaningful validation error.

Example:

```text
Validation Error

Field:
query

Expected:
string

Received:
integer
```

This makes debugging much easier.
