## 2. What Is a Dataset?

A dataset is a structured collection of information used to train, validate or evaluate a machine learning model.

For fine-tuning, a dataset contains examples that demonstrate how a model should respond to particular instructions.

For MarketMate AI, the dataset teaches the model how to handle marketing tasks such as:

- Target audience analysis.
- Brand positioning.
- Brand voice adaptation.
- Social media content creation.
- Marketing campaign planning.
- Product messaging.
- Marketing strategy.

**Simple example:**

A user asks:

"Create an Instagram caption for a clothing brand."

The dataset contains an example of what a good marketing assistant should produce.

The model learns response patterns from many such examples.

## 3. Data Sourcing

Data sourcing means collecting existing information from relevant and reliable sources.

Possible sources for MarketMate AI include:

- Public marketing guides.
- Marketing case studies.
- Public business reports.
- Open datasets with suitable licences.
- Brand information provided with permission.
- Realistic business scenarios.

### Important considerations

Before using external data, check:

1. Is the source reliable?
2. Do I have permission to use the material?
3. Is the information relevant to my task?
4. Is the information accurate and current?
5. Does it contain personal or confidential information?

Avoid copying entire copyrighted articles or commercial marketing materials into the training dataset without permission.

## 4. Data Synthesis

Data synthesis means creating new examples instead of collecting existing ones.

For example:

**Scenario:**

A small clothing brand sells oversized T-shirts to university students.

We create an instruction:

"Identify the target audience for this business."

We then write an ideal response describing the likely audience, customer needs and assumptions.

This becomes a synthetic training example.

### Why use synthetic data?

- We can create examples for specific tasks.
- We control the difficulty and structure.
- We can cover different business scenarios.
- We can create examples for situations where information is missing.
- We can avoid unnecessary personal information.

However, synthetic data can contain incorrect assumptions or repetitive patterns. It must be reviewed.

## 5. Data Curation

Data curation means selecting, organising, cleaning and reviewing data before using it.

Not every example should enter a training dataset.

For example:

| Low-quality example | Improved example |
|---|---|
| Write something for Instagram. | Write an Instagram caption for a new clothing collection targeting university students. |
| Make a marketing plan. | Create a two-week Instagram campaign for a small clothing brand launching oversized T-shirts. |
| Sell this product. | Write a product description using the supplied product features without inventing additional claims. |

Good curation improves the consistency and usefulness of the training examples.

## 6. Understanding Instruction-Following Data

MarketMate AI uses instruction-following examples.

Each example contains three main components:

| Component | Purpose |
|---|---|
| Instruction | Tells the model what to do. |
| Input | Provides relevant business information. |
| Output | Shows the expected response. |

### Example

Instruction:

Identify the target audience for this business.

Input:

A small clothing brand sells affordable oversized T-shirts aimed at university students.

Output:

The primary target audience is university students who want comfortable, affordable and casual clothing. Their likely interests include relaxed fashion and versatile everyday outfits.

The model learns the relationship between the instruction, input and expected output.

## 7. What Is JSONL?

JSONL stands for JavaScript Object Notation Lines.

It is a text-based format where each line contains one independent JSON object.

Example:

```jsonl
{"instruction":"Create an Instagram caption.","input":"A coffee shop is launching a new iced coffee menu.","output":"Your next coffee break just got cooler. Explore our new iced coffee menu today."}
{"instruction":"Identify the target audience.","input":"A business sells affordable gym clothing for beginners.","output":"Potential customers include people starting their fitness journey who want accessible and practical workout clothing."}
```

### JSON vs JSONL

| JSON | JSONL |
|---|---|
| Usually stores data in one JSON structure. | Stores one JSON object per line. |
| Often uses arrays for multiple records. | Each line is an independent record. |
| Useful for structured data storage. | Convenient for large datasets and training pipelines. |

### Important JSONL rules

1. Each line must contain one valid JSON object.
2. Use double quotes around keys and string values.
3. Do not add commas between separate lines.
4. Avoid comments inside the file.
5. Keep field names consistent.

## 8. Dataset Quality

A good dataset should have the following characteristics:

**Accuracy:** The output should contain correct information.

**Relevance:** The response should directly answer the instruction.

**Clarity:** Instructions and outputs should be easy to understand.

**Consistency:** Similar tasks should follow a consistent structure.

**Diversity:** Examples should cover different industries, customers and marketing situations.

**Originality:** Avoid unnecessary duplication.

**Constraint awareness:** The model should not invent missing business information.

### Example of a missing-information scenario

Input:

"A business wants to increase sales."

A weak assistant immediately creates a detailed marketing strategy without knowing anything about the business.

A better assistant asks:

- What product or service do you sell?
- Who are your target customers?
- Which marketing channels do you currently use?
- What is your available budget?

This teaches the model to recognise when additional information is necessary.

## 9. Training, Validation and Test Data

A dataset should be separated into different subsets.

| Dataset | Purpose | Proposed size |
|---|---|---:|
| Training | Used to train the model. | 80 |
| Validation | Used to monitor and adjust training. | 10 |
| Testing | Used for final evaluation. | 10 |
| Total | | 100 |

These numbers represent our initial dataset plan.

### Why separate the data?

**Training data:** The model learns from these examples.

**Validation data:** Helps assess performance during development.

**Test data:** Measures performance on examples the model has not trained on.

Never use the test set to train the model. Keep it separate to avoid data leakage.

## 10. Common Dataset Problems

| Problem | Explanation |
|---|---|
| Duplicate examples | The same instruction appears repeatedly with minor wording changes. |
| Incorrect answers | Outputs contain inaccurate information. |
| Missing context | Instructions do not provide enough information. |
| Biased data | Examples repeatedly assume the same type of customer. |
| Hallucinated claims | Outputs invent statistics, testimonials or product features. |
| Poor formatting | JSONL records are invalid or inconsistent. |
| Data leakage | Test examples accidentally appear in training data. |

A larger dataset is not automatically a better dataset.

Quality, diversity and relevance are important.
