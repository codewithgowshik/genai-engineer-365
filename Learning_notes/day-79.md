# 1. Embedding Models

An **embedding model** converts text into numerical vectors.

```text
Text
 ↓
Tokenization
 ↓
Token IDs
 ↓
Embedding Model
 ↓
384-dimensional vector
```

For this project we use:

```python
model = SentenceTransformer("all-MiniLM-L6-v2")
```

`all-MiniLM-L6-v2` is a pretrained embedding model that produces a **384-dimensional embedding** for each input text.

---

# 2. What Does 384 Dimensions Mean?

One sentence becomes **one vector containing 384 numerical values**.

It does not mean the sentence is split into 384 pieces.

Example:

```text
"I love programming"

        ↓

[0.12, -0.43, 0.71, 0.08, ...]
```

The vector contains 384 values when using `all-MiniLM-L6-v2`.

If we have six sentences:

```text
Sentence 1 → 384 values
Sentence 2 → 384 values
Sentence 3 → 384 values
Sentence 4 → 384 values
Sentence 5 → 384 values
Sentence 6 → 384 values
```

Therefore:

```text
(6, 384)
```

means:

```text
6 vectors × 384 dimensions
```

# 4. Cosine Similarity

Cosine similarity compares the direction of two vectors.

The formula is:

$$
\text{cosine similarity}(A,B)
=
\frac{A \cdot B}
{\|A\|\|B\|}
$$

Where:

- `A` = first embedding vector
- `B` = second embedding vector
- `A · B` = dot product
- `||A||` = magnitude/norm of vector A
- `||B||` = magnitude/norm of vector B

Conceptually:

```text
Similar meaning
      ↓
Similar vector direction
      ↓
Higher cosine similarity
```

---

# 5. Cosine Similarity Range

Cosine similarity mathematically ranges from:

```text
-1 ───────── 0 ───────── +1
```

Conceptually:

```text
-1 → opposite direction

 0 → perpendicular / little directional similarity

+1 → same direction
```

For semantic embeddings, you will commonly work with positive similarity values.

A higher score generally indicates greater semantic similarity.

---

# 6. Example

Consider:

```text
Sentence A:
"I love programming in Python."

Sentence B:
"Python is my favourite programming language."
```

Their embeddings might look conceptually like:

```text
A → [0.12, -0.43, 0.71, ... 384 values]

B → [0.15, -0.39, 0.68, ... 384 values]
```

Cosine similarity compares the two vectors.

Because the sentences have related meanings, we expect a relatively high similarity score.

Compare:

```text
"I love programming in Python."

"Pizza is one of my favourite foods."
```

These sentences have less related meanings, so we generally expect a lower similarity score.

# 7. Build — Generate Embeddings

```python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity


model = SentenceTransformer("all-MiniLM-L6-v2")


sentences = [
    "I love programming in Python.",
    "Python is my favourite programming language.",
    "I enjoy building software.",
    "I enjoy eating pizza.",
    "Pizza is one of my favourite foods.",
    "I love travelling around Europe.",
]


# Generate embeddings
embeddings = model.encode(sentences)

print("Number of sentences:", len(sentences))
print("Embedding shape:", embeddings.shape)
```

Expected shape:

```text
(6, 384)
```

---

# 8. Calculate Cosine Similarity

```python
similarity_matrix = cosine_similarity(embeddings)

print("Similarity Matrix:")
print(similarity_matrix)
```

The function compares every embedding with every other embedding.

With six sentences, the result is a:

```text
6 × 6
```

similarity matrix.

Conceptually:

```text
       S1    S2    S3    S4    S5    S6

S1    1.00  0.80  0.60  ...
S2    0.80  1.00  0.65  ...
S3    0.60  0.65  1.00  ...
...
```

The exact values depend on the embeddings generated by the model.

---

# 9. Why Is the Diagonal 1?

Each sentence is compared with itself.

For example:

```text
S1 ↔ S1
```

A vector compared with itself has maximum cosine similarity:

$$
\text{cosine similarity}(A,A)=1
$$

Therefore, the diagonal of the similarity matrix contains `1`s.

---

# 10. Finding the Most Similar Sentences

We can search the similarity matrix to find the highest similarity score between different sentences.

```python
best_score = -1
best_pair = None

for i in range(len(sentences)):
    for j in range(i + 1, len(sentences)):

        score = similarity_matrix[i][j]

        if score > best_score:
            best_score = score
            best_pair = (i, j)


i, j = best_pair

print("Most similar sentences:")
print("Sentence 1:", sentences[i])
print("Sentence 2:", sentences[j])
print("Cosine similarity:", round(best_score, 4))
```

The program checks different sentence pairs and keeps the pair with the highest similarity score.

---

# 11. Why Are We Using `i + 1`?

This:

```python
for j in range(i + 1, len(sentences)):
```

prevents unnecessary comparisons.

We don't need:

```text
S1 ↔ S1
```

because we already know it is `1`.

We also don't need both:

```text
S1 ↔ S2
S2 ↔ S1
```

because cosine similarity is symmetric:

$$
\text{cosine similarity}(A,B)
=
\text{cosine similarity}(B,A)
$$

So we only calculate each unique pair once.

---

# 12. Semantic Similarity

The important concept is that we are not simply checking whether the sentences contain the same words.

For example:

```text
"I love programming in Python."

"Python is my favourite programming language."
```

They use different wording, but their meanings are related.

Embeddings allow us to compare their **semantic representations**.

This is why embeddings are useful for semantic search.

---

# 13. Key Formulas

### Dot product

$$
A \cdot B
=
\sum_i a_i b_i
$$

### Vector magnitude

$$
\|A\|
=
\sqrt{\sum_i a_i^2}
$$

### Cosine similarity

$$
\text{cosine similarity}(A,B)
=
\frac{A \cdot B}
{\|A\|\|B\|}
$$

### Euclidean distance

$$
d(A,B)
=
\sqrt{\sum_i(a_i-b_i)^2}
$$
