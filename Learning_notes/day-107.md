## 1. Caching and Performance

Streamlit can rerun the Python application when the user interacts with the interface.

For example:

```text
User changes something
      ↓
Streamlit reruns
      ↓
Python code executes
      ↓
UI updates
```

If expensive resources are repeatedly created or loaded, this can make the application slower.

Caching helps avoid unnecessary repeated work.

---

## 2. What is Caching?

Caching means storing something that is expensive to create or calculate so that it can be reused later.

Without caching:

```text
Request 1 → Load resource
Request 2 → Load resource
Request 3 → Load resource
```

With caching:

```text
Request 1 → Load resource → Store
Request 2 → Reuse resource
Request 3 → Reuse resource
```

The main idea is:

> **Do expensive work once and reuse the result when possible.**

---

## 3. `st.cache_resource`

Streamlit provides:

```python
@st.cache_resource
```

for resources such as machine learning models.

Example:

```python
import streamlit as st
from sentence_transformers import SentenceTransformer


@st.cache_resource
def load_model():

    return SentenceTransformer(
        "all-MiniLM-L6-v2"
    )


model = load_model()
```

The first time the function runs, the model is loaded.

Later Streamlit reruns can reuse the cached resource.

---

## 4. Why Cache an Embedding Model?

The Semantic Search Engine uses:

```text
all-MiniLM-L6-v2
```

to create embeddings.

Loading an embedding model is more expensive than ordinary UI operations.

Caching allows the model to be reused rather than unnecessarily recreated during Streamlit reruns.

The basic idea is:

```text
Embedding Model
      ↓
Expensive Resource
      ↓
Cache
      ↓
Reuse
```


## 11. Empty States

An **empty state** is what the application shows when there is nothing to display.

There are two useful cases.

### Empty Query

If the user hasn't entered anything:

```python
st.warning(
    "Please enter a search query."
)
```

### No Results

If a search returns no documents:

```python
st.info(
    "No results found."
)
```

These messages give the user feedback instead of leaving the interface blank.

## 13. Complete Day-107 UI Example

```python
import streamlit as st

from src.search import search


st.set_page_config(
    page_title="Semantic Search Engine",
    page_icon="🔎",
    layout="centered"
)


st.title("🔎 Semantic Search Engine")

st.write(
    "Search documents by meaning, "
    "not just exact keywords."
)


st.divider()


query = st.text_input(
    "Search",
    placeholder="Example: I want to learn programming"
)


k = st.selectbox(
    "Number of results",
    [1, 2, 3, 4],
    index=2
)


if st.button(
    "Search",
    type="primary"
):

    if query.strip() == "":
        st.warning(
            "Please enter a search query."
        )

    else:

        results = search(
            query,
            k=k
        )

        documents = results["documents"][0]

        st.subheader(
            f"Search Results ({len(documents)})"
        )

        if len(documents) == 0:

            st.info(
                "No results found."
            )

        else:

            for i, document in enumerate(documents):

                with st.container(border=True):

                    st.markdown(
                        f"**Result {i + 1}**"
                    )

                    st.write(document)
```
