# Day 102 — Build a Streamlit UI

## Objective

Build a simple user interface for the **Semantic Search Engine** using Streamlit.

Today connects the search backend built on Day 101 to a user-facing web interface.

---

## 1. What is Streamlit?

Streamlit is a Python framework for building simple web interfaces for Python applications.

It allows us to create a user interface using Python without needing to build the frontend separately.

For this project, Streamlit provides the interface where a user can enter a search query and see the semantic search results.

---

## 2. Why do we need a UI?

Before Day 102, the search engine could be used through Python code.

The user would provide a query to the search function, and the backend would return results.

A UI makes the system easier for a real user to interact with.

The user can:

1. Enter a search query.
2. Click Search.
3. Send the query to the search backend.
4. Receive the top search results.
5. Read the results on the page.

---

The project now has this flow:



The UI does not perform the search itself.

## 4. Streamlit Components Used

Today's UI uses a small number of Streamlit components.

### `st.title()`

Displays the main page title.

### `st.text_input()`

Creates a text box where the user can enter a search query.

### `st.button()`

Creates a button that the user can click.

### `st.warning()`

Displays a warning message.

### `st.subheader()`

Creates a section heading.

### `st.write()`

Displays text and search results.

---

## 5. Today's Build

Create an `app.py` file in the project root.

The basic application connects the UI to the existing `search()` function.

```python
import streamlit as st
from src.search import search


st.title("Semantic Search Engine")

query = st.text_input("Enter your search query")

if st.button("Search"):

    if query.strip() == "":
        st.warning("Please enter a search query.")

    else:
        results = search(query, k=3)

        st.subheader("Search Results")

        for i, document in enumerate(results["documents"][0]):
            st.write(f"**Result {i + 1}**")
            st.write(document)
```

---

## 6. How the Code Works

### Step 1 — Import Streamlit

```python
import streamlit as st
```

This gives the application access to Streamlit's UI components.

### Step 2 — Import the search backend

```python
from src.search import search
```

This reuses the search function created on Day 101.

We do not need to rebuild the search logic.

### Step 3 — Create the title

```python
st.title("Semantic Search Engine")
```

This displays the application title.

### Step 4 — Get the user's query

```python
query = st.text_input("Enter your search query")
```

The text entered by the user is stored in the `query` variable.

### Step 5 — Check the Search button

```python
if st.button("Search"):
```

The code inside this block runs when the user clicks Search.

### Step 6 — Check for an empty query

```python
if query.strip() == "":
```

This prevents an empty search from being sent to the backend.

### Step 7 — Call the search backend

```python
results = search(query, k=3)
```

The query is sent to the existing search backend.

`k=3` means we request the top three results.

### Step 8 — Display the results

```python
for i, document in enumerate(results["documents"][0]):
```

The returned documents are displayed one by one.

## 7. Running the UI

First activate the virtual environment.

On Windows PowerShell:

```bash
.\\venv\\Scripts\\Activate.ps1
```

If the environment is named `.venv`:

```bash
.\\.venv\\Scripts\\Activate.ps1
```

Install Streamlit:

```bash
pip install streamlit
```

Update the requirements file:

```bash
pip freeze > requirements.txt
```

Then run the application from the project root:

```bash
streamlit run app.py
```

Streamlit will provide a local address, normally similar to:

```text
http://localhost:8501
```

Open that address in the browser.

## 9. Important Debugging Lesson

If the Streamlit page does not display correctly, simplify the application first.

For example:

```python
import streamlit as st

st.title("Semantic Search Engine")

st.write("Streamlit is working!")
```

If this works, Streamlit itself is running correctly.

The problem can then be investigated in the connection between the UI and the search backend.

This is a useful debugging approach:

```text
Test UI
  ↓
Test backend connection
  ↓
Test database/search
```
