# Day 178: Fine-tuning the Model

## 1. What is Fine-tuning?

Fine-tuning is the process of taking a pretrained language model and training it further on a specific dataset to improve its performance on a particular task.

A pretrained model already understands language, but fine-tuning helps it learn task-specific patterns, instructions and response formats.

For our MarketMate AI project, we are fine-tuning a model to behave like a digital marketing assistant.

## 2. Understanding the Training Plan

Our fine-tuning pipeline consists of five stages:

1. Load the pretrained model.
2. Load the training dataset.
3. Tokenize the dataset.
4. Apply LoRA and train the model.
5. Save the trained adapter.

Each stage prepares the model for the next step.

## 3. Dataset Formatting

Our original dataset was stored in JSONL format with three fields:

- Instruction
- Input
- Output

We used Hugging Face's `.map()` method to apply a formatting function to all 20 examples.

This combined the three fields into a single text sequence.

Example:

### Before formatting

```json
{
  "instruction": "Identify the target audience",
  "input": "A clothing brand sells oversized T-shirts",
  "output": "University students are the primary audience."
}
```

### After formatting

```text
### Instruction:
Identify the target audience

### Input:
A clothing brand sells oversized T-shirts

### Response:
University students are the primary audience.
```

Formatting creates a consistent structure for the training examples.

## 4. Loading the Base Model

We selected Qwen2.5-0.5B from Hugging Face.

A base model is a pretrained language model that provides the foundation for our fine-tuning process.

We loaded two components:

**Tokenizer:** Converts text into numerical tokens that the model can process.

**Base model:** The pretrained neural network that we will adapt using LoRA.

## 5. Understanding LoRA

LoRA stands for Low-Rank Adaptation.

It is a parameter-efficient fine-tuning technique that allows us to adapt a large pretrained model without updating all its original parameters.

Instead of training the entire model, LoRA introduces smaller trainable matrices into selected layers.

This reduces the number of trainable parameters and makes fine-tuning more resource-efficient.

### Our LoRA configuration

| Parameter | Value |
|---|---|
| Rank (r) | 8 |
| Alpha | 16 |
| Dropout | 0.05 |
| Bias | None |
| Task type | Causal Language Modelling |
| Target modules | q_proj, v_proj |

**Rank:** Controls the dimensions of the low-rank matrices.

**Alpha:** Controls the scaling of the LoRA updates.

**Dropout:** Helps reduce overfitting by randomly dropping some activations during training.

**Target modules:** Specify which model layers receive LoRA adapters.

## 6. Understanding Hugging Face PEFT

We used the PEFT library to implement LoRA.

The `LoraConfig()` function defines the adapter configuration.

The `get_peft_model()` function attaches the adapters to the pretrained model.

We also used `print_trainable_parameters()` to inspect how many parameters can be updated during training.

## 8. Key Learnings

- Fine-tuning adapts pretrained models to specialised tasks.
- JSONL provides a structured format for training examples.
- Hugging Face `.map()` applies transformations across dataset examples.
- Tokenizers convert text into numerical representations.
- LoRA reduces the number of parameters that need to be trained.
- PEFT provides tools for parameter-efficient fine-tuning.
- A trained LoRA adapter can be saved separately from the original base model.
