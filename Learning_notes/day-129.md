# Day 129 — Implement Rank Fusion

## Objective

Today I learned about **Reciprocal Rank Fusion (RRF)** and implemented a simple rank-fusion system.

The goal is to combine multiple ranked search results into one final ranking.

## What Is Rank Fusion?

Different retrieval methods can return different rankings for the same question.

For example:

```text
Semantic Search:
1. Python
2. Java
3. C++

Keyword Search:
1. Java
2. Python
3. JavaScript
```

Both searches found useful results, but they ranked them differently.

**Rank fusion combines these rankings into one ranking.**

## What Is Reciprocal Rank Fusion?

Reciprocal Rank Fusion (RRF) gives a score to a document based on its position in each ranked list.

The basic formula is:

```text
RRF Score = Σ 1 / (k + rank)
```

Where:

- `rank` is the document's position in a result list.
- `k` is a constant, commonly `60`.
- The scores from different result lists are added together.

The important idea is simple:

> Documents that appear near the top of multiple rankings receive a stronger combined score.

## Simple Example

Suppose two searches return:

```text
Search 1:
1. Python
2. Java
3. C++

Search 2:
1. Java
2. Python
3. JavaScript
```

Python appears at positions `1` and `2`.

Java appears at positions `2` and `1`.

JavaScript appears only at position `3`.

RRF rewards documents that consistently rank highly across different searches.

## Why RRF Helps RAG

A RAG system can use several retrieval strategies, such as:

- Semantic search
- Keyword search
- Multi-query retrieval

Each method can produce its own ranked list.

RRF can combine those lists:

```text
Semantic Search ──┐
Keyword Search  ──┼──→ RRF → Combined Ranking
Multi-Query     ──┘
```

The combined ranking can then be used to select the best documents for the RAG context.

## RRF vs Hybrid Scoring

Hybrid search can combine numerical scores, for example:

```text
Combined Score =
(Keyword Score × 0.3) +
(Semantic Score × 0.7)
```

RRF works differently. It focuses on the **rank position** of a document in each result list instead of directly combining the original retrieval scores.

## Python Concepts Used

### `enumerate()`

`enumerate()` gives both the position and the item while looping.

```python
for rank, document in enumerate(results, start=1):
```

This gives:

```text
1 → first document
2 → second document
3 → third document
```

`start=1` makes the ranking begin at 1 instead of Python's default 0.

### `lambda`

A lambda is a small one-line function.

```python
lambda x: x[1]
```

In the sorting code, it tells Python to use the second value of each result as the sorting value.

### `.6f`

This formats a decimal number with six digits after the decimal point.

```python
f"{score:.6f}"
```

For example:

```text
0.032786885
```

becomes approximately:

```text
0.032787
```
